# 26xV01Q 点云拼接、截面测量与 CAD 对比软件

## 1. 文档目的

本文档是当前软件的设计基线和后续重构依据，目标是把软件从“能运行的点云处理脚本”整理成一套可现场复用、可追溯、可验收的测量系统。

本项目引用的专利文档只作为工程参考，不要求完全复制其算法。可借鉴的内容只有以下几类：

- 用稳定的标定块或公共几何特征建立统一坐标系；
- 用多个几何特征共同约束位姿，而不是让一次宽松 ICP 决定全部姿态；
- 对多视角结果进行公共覆盖区验证；
- 保留各视角的互补覆盖，最后再做轮廓提取和 CAD 对比。

当前系统的目标对象是多次拍摄得到的 5-8 组点云。拍摄的目的不是寻找一块“大家都看到的区域”，而是用不同角度把目标件完整拍全，再把各视角映射到同一坐标系中融合。

## 2. 产品边界

### 2.1 输入

- 3D 线激光或结构光相机输出的 PLY 点云；
- 一组零件的 5-8 个视角；
- 每个视角可见的多面体标定块；
- 需要检测的目标区域；
- CAD 截面或 DXF 线框；
- 可选的采集清单，包含工位、相机、时间和采集顺序。

### 2.2 输出

- 统一坐标系下的目标件融合点云；
- 融合云基线截面点云和最终截面点云；
- 多视角对齐审计图；
- 多截面覆盖和错层诊断图；
- CAD 配准、法向偏差和角度测量结果；
- 带版本、参数、质量闸门和来源信息的 `run_summary.json`。

### 2.3 明确不做的事情

- 不用 CAD 反向移动、旋转、缩放或补齐实测点云；
- 不通过插值、补线、加厚截面制造不存在的点；
- 不因为某个视角与其他视角没有重叠，就删除它的独有覆盖；
- 不把标定块写入最终被测件融合云；
- 不把“邻近平面看起来更完整”当成当前正式测量截面；
- 不用工件表面反向修改由标定块确定的位姿；
- 不在质量不合格时输出正式 `PASS`。

## 3. 当前实现评估

当前代码已经具备以下正确方向：

1. `pipeline.py` 负责去噪、标定块 ROI、刚体配准、位姿图、融合、截面和审计输出。
2. 5/6 工位使用固定工位姿态先验，7/8 工位使用标定块 ROI 进行通用初始定位。
3. 标定块参与位姿计算，但默认从最终目标融合云中排除。
4. ICP 采用多尺度策略，并限制旋转和平移修正量。
5. 位姿图只使用标定块，不使用工件或 CAD 回写位姿。
6. 融合采用真实代表点，不输出体素坐标平均值；完成融合后仅清理小型、紧凑、弱支持且与主体断开的孤立组件。
7. 单视角独有区域被保留，截面共识只用于诊断或局部重复点选择。
8. 截面直接从清理后的融合云提取，不再执行统计或二维连通域清噪；基线/最终截面比较只用于两者的结构完整性诊断，不能单独证明融合云清理无损。
9. CAD 下游有固定点云输入契约和正式测量质量闸门。
10. 页面支持不同点云族独立使用参数 profile。

当前已确认的主要问题：

- `plus37` 和 `minus50` 的截面仍存在持续错层或轮廓不一致；
- `minus50` 的标定块几何候选需要过大的旋转和平移修正，已被保护逻辑拒绝；
- `木板-4` 的多截面诊断为 `persistent_gap`，不能作为正式测量数据；
- 当前融合点数和截面点数变化很小，说明主要问题不是体素融合丢点，而是姿态、ROI 或实际采集覆盖；
- 固定工位矩阵仍有硬编码痕迹，现场正式使用需要外部化、版本化和可追溯；
- `pipeline.py` 和 `app.py` 过于集中，长期维护和现场排障成本高；
- 旧版脚本和旧流程仍在目录中，容易造成操作员误启动或误解流程。

## 4. 应删除、应保留、应重写

### 4.1 应从正式生产路径删除

以下逻辑不应再成为正式测量路径的一部分：

- 由工件全云 ICP 反向决定最终姿态的旧路径；
- 以共同重叠区域为依据删除互补视角的逻辑；
- 只保留共识轮廓、丢弃单视角独有覆盖的逻辑；
- 用加厚切片、插值、连线或平滑补齐断口的逻辑；
- 用邻近横截面替代操作者选定中心截面的逻辑；
- 没有质量证据仍输出正式 `PASS` 的逻辑；
- 依赖文件遍历顺序直接推断工位的正式路径；
- 任何把 CAD 拟合结果写回点云坐标的路径。

这些代码如果还有调试价值，应移动到 `legacy/` 或显式的“诊断实验”模块，不能由正式按钮隐式调用。

### 4.2 应保留

- 标定块 ROI 隔离；
- 标定块近水平面调平；
- 固定工位先验作为初始值；
- 标定块多平面几何约束；
- 多尺度 ICP；
- 只使用标定块的位姿图；
- 覆盖优先的融合；
- 融合云基线截面和最终截面同时保存；
- 多截面诊断；
- CAD 输入契约和正式测量质量闸门；
- 人工工位修正入口，但必须有范围限制和审计记录。

### 4.3 应重写

#### 工位识别

当前文件时间顺序只能作为兼容回退，正式流程改为：

```text
采集清单/相机元数据 > 文件名工位标签 > 文件时间顺序
```

没有可靠工位标签时，软件必须标记 `station_order_uncertain=true`，并要求人工确认后才能进行正式测量。

#### 固定姿态矩阵

当前内置矩阵保留为兼容默认值，但正式设计改为：

- 每个零件族使用独立的 `station_calibration.json`；
- 文件包含相机、标定块、坐标单位、标定日期、版本、有效范围和残差；
- 运行摘要记录校准文件哈希；
- 内置矩阵只用于首次迁移或没有外部校准文件时的临时初值。

#### 标定块几何匹配

当前已经有平面法向、中心、跨度和点数约束。后续重写为两级策略：

1. 提取平面、边缘、角点和面间距等特征；
2. 生成多个候选匹配，使用整体几何残差和运动边界选出候选；
3. 候选不唯一时不强行选择，返回 `ambiguous_geometry`；
4. 只有候选稳定时才进入 ICP；
5. ICP 只能在候选附近做小范围精调。

#### 融合

融合接口应显式区分：

```text
transformed_target_clouds
fixture_exclusion
representative_voxel_selection
provenance_map
```

不能让一个函数同时隐式完成“姿态估计、工件筛选、共识删除和写文件”。

#### 截面

截面模块应拆成三个独立动作：

1. `extract_section`：从已完成融合后孤立组件清理的点云按真实平面取点；
2. `diagnose_section`：对相邻平面、多视角来源和覆盖缺口做诊断；
3. `freeze_final_section`：冻结提取出的点集供 CAD 使用，不在截面阶段再次执行统计或二维连通域清噪。

相邻平面扫描结果只能产生建议，必须由操作者确认后才写入下一次处理参数。

#### CAD 测量

CAD 模块必须接收已冻结的最终截面，输出：

- CAD 配准变换；
- 每条测量路径的点到线或点到局部法向距离；
- 角度偏差；
- 点数、覆盖跨度、残差和置信等级。

CAD 模块不能修改上游融合云或截面。

## 5. 目标总体架构

长期目标是把当前集中式实现拆为以下层次：

```text
app.py
  └─ workflow / 页面状态 / 结果展示

pointcloud_app/
  ├─ io.py             PLY、采集清单、运行目录、哈希
  ├─ preprocessing.py  去噪、单位检查、点云质量统计
  ├─ calibration.py    ROI、平面/边缘特征、调平、校准文件
  ├─ registration.py   初始位姿、ICP、候选、位姿图
  ├─ fusion.py         标定块排除、覆盖优先融合、来源追踪
  ├─ sections.py       平面定义、截面提取、清理、诊断
  ├─ quality.py        所有质量指标、闸门和状态机
  ├─ reporting.py      图片、JSON、CSV、审计报告
  ├─ downstream_bridge.py
  └─ legacy/           旧流程，仅供迁移和回归比较
```

短期不要求一次性拆完。第一步只把 `process_group` 变成编排函数，把实际算法迁入独立模块；旧函数通过兼容包装保留一个版本周期。

## 6. 推荐正式处理流程

### 阶段 A：输入检查

1. 读取组目录和采集清单。
2. 校验 PLY 头、单位、坐标有限性、点数和颜色字段。
3. 显示每个视角的原始点数、包围盒和预计工位。
4. 没有明确工位映射时要求确认。
5. 保存输入文件哈希，保证运行可复现。

### 阶段 B：点云预处理

每个视角保留三份概念数据：

```text
raw_cloud                 原始输入，只读
registration_cloud        用于标定块和 ICP 的降采样云
target_full_resolution    用于最终覆盖融合的全分辨率目标云
```

去噪规则：

- 先做有限值和明显非法点剔除；
- 再做适度体素降采样；
- 统计滤波只用于离群点；
- 半径滤波只在现场噪声验证后启用；
- 任何去噪都记录输入点数、保留点数和删除比例。

### 阶段 C：标定块和统一坐标系

1. 在每个原始坐标系内裁剪标定块 ROI。
2. 检查标定块点数和空间跨度。
3. 从参考视角拟合近水平面，生成调平变换。
4. 5/6 工位使用外部化姿态先验作为初值。
5. 7/8 工位使用标定块特征求粗位姿。
6. 对每个非参考视角执行：
   - 平面、边缘或角点候选匹配；
   - 小范围刚体修正；
   - 多尺度 ICP；
   - 旋转、平移、RMSE、fitness 和几何残差检查。
7. 仅将标定块进入位姿图。
8. 位姿图优化只允许小修正，拒绝异常闭环边。

统一坐标变换定义为：

```text
p_reference = T_leveling · T_station · p_source
```

所有变换必须以 4x4 刚体矩阵保存，并记录矩阵来源。

### 阶段 D：标定块质量闸门

建议正式测量至少满足：

- 标定块有效点数达到 profile 要求；
- 至少 3 个稳定、非共线的几何平面或等价特征；
- 标定块 ICP fitness 达到 profile 阈值；
- 标定块 ICP RMSE 不超过 profile 阈值；
- 刚体修正旋转和平移在限制内；
- 位姿图关键边没有被拒绝；
- 工位顺序已确认。

失败工位有两种处理：

1. `calibration_invalid`：不进入位姿图和融合；
2. `calibration_valid_but_section_warning`：可参与覆盖融合，但不能单独证明截面可靠。

### 阶段 E：覆盖优先融合

1. 将所有标定块质量合格视角的目标全分辨率点云变换到参考坐标。
2. 在各自本地坐标中排除标定块 ROI，防止调平后轴对齐盒扩大。
3. 不使用共同区域筛选全云。
4. 以体素做重复点管理，但每个体素选择一个真实输入点：
   - 距体素中心最近；
   - 距离相同时按来源稳定排序；
   - 不输出多个输入点的坐标平均值。
5. 保存来源索引、支持视角数和代表点残差。
6. 单视角独有体素必须保留。

融合结果同时提供：

- 目标融合云；
- 各来源覆盖数量；
- 单视角独有覆盖比例；
- 多视角重叠比例；
- 代表点残差；
- 标定块排除数量。

### 阶段 F：截面提取和诊断

截面定义：

```text
abs(n · p - d) <= thickness / 2
```

正式截面处理顺序：

1. 操作者选择目标区域和中心平面；
2. 在完整融合云上仅清理小型、紧凑、弱支持且与主体断开的孤立组件；
3. 从清理后的融合云提取目标截面，并保存基线截面和最终截面文件；
4. 扫描中心附近多个平行探针；
5. 评估每个探针的点数、连续性、跨度、分量数和多视角支持；
6. 对各工位比较共同覆盖区域；
7. 判断缺口来自：
    - 原始采集覆盖不足；
    - 姿态错层；
    - 截面平面位置不合适；
    - 融合后孤立组件清理造成结构变化。
8. 记录基线/最终截面对比结果；两者均来自融合清理后，不能作为融合清理前后对比。清理影响需另行复核组件记录和源点云，发现结构性变化时暂停正式 CAD。

状态定义：

- `center_only_stable`：中心截面暂时可用，但邻近证据不足；
- `stable_neighbor_sections`：邻近截面稳定，中心仍需人工确认；
- `persistent_gap`：多个平面均存在缺口；
- `source_coverage_gap_likely`：原始数据覆盖不足；
- `mismatch`：共同覆盖区存在错层或重影；
- `coverage_only`：只有互补覆盖，不能判断共同轮廓；
- `pass`：共同覆盖区通过，且没有持续异常证据。

### 阶段 G：CAD 对比

1. 只读取已冻结的 `vertical_section.ply`。
2. 导入 DXF 后建立实体索引和连接拓扑。
3. 操作者选择一条 CAD 基准线进行注册。
4. 操作者选择一条或多条连续 CAD 路径作为测量路径。
5. 对每条路径计算：
   - 局部法向距离；
   - 最大、平均、P90 偏差；
   - 起止角度；
   - 有效点数和覆盖比例。
6. 生成 CAD 叠加图、偏差颜色图和结构化报告。
7. 质量闸门不通过时可以显示参考数值，但报告必须标记：

```text
formal_measurement_allowed = false
```

## 7. 质量状态机

建议统一使用以下状态：

```text
INPUT_INVALID
CALIBRATION_INVALID
POSE_UNCERTAIN
FUSION_READY
SECTION_INSUFFICIENT
SECTION_WARNING
CAD_REFERENCE_ONLY
FORMAL_PASS
FORMAL_FAIL
```

正式测量条件：

```text
输入有效
且工位顺序已确认
且标定块质量合格
且融合视角数达到最小值
且截面完整性证据充分
且没有 persistent_gap
且没有未确认的姿态或截面建议
```

覆盖优先只影响“是否保留点云”，不影响“是否允许正式出值”。

## 8. 参数 profile 设计

参数必须按零件族保存，不允许操作员在不同组之间无意共享状态。

### 木板类初始 profile

当前可作为起点，后续根据现场重复性重新标定：

- 去噪体素：`0.12`
- 统计邻居：`20`
- 统计标准差倍率：`2.0`
- 标定块 ROI：按设备坐标单独校验
- 标定块最少点数：`800`
- 注册体素：`0.28`
- ICP 最大对应距离：`0.8`
- ICP 迭代：`180`
- 位姿图标定体素：`0.08`
- 融合体素：`0.03`
- 截面厚度：`0.15`
- 多截面探针：`5` 个，间隔 `0.5`

这些数值不是通用常数。现场应通过标准件重复测量确定最终值，并把设备、零件族和版本写进 profile。

## 9. 现场使用流程

### 操作员流程

1. 创建或选择零件组。
2. 导入 5-8 个点云。
3. 确认每个文件对应的工位。
4. 检查每个视角的标定块 ROI。
5. 运行点云处理。
6. 先看标定块叠加图和工位质量表。
7. 再看多截面诊断图和融合云基线截面图。
8. 如果有异常工位，只调整该工位，不修改全局参数。
9. 重新运行并比较两次运行摘要。
10. 只有质量状态为 `FORMAL_PASS` 才进入 CAD 正式测量。

### 现场禁止操作

- 不能为了填满缺口直接把厚度调大；
- 不能用 CAD 轮廓补线；
- 不能把单张截图看起来连续作为合格依据；
- 不能跳过标定块质量表直接导出报告；
- 不能把多次运行的截面文件混用。

## 10. 当前 `木板-4` 的专项处理方案

当前已知问题集中在 `plus37` 和 `minus50`，建议按以下顺序排查：

1. 在页面中单独显示这两个工位的原始点云和标定块 ROI。
2. 确认 ROI 中至少包含 3 个稳定几何平面，并且没有混入目标件主体。
3. 确认文件和工位标签对应关系，不依赖文件时间顺序猜测。
4. 查看标定块几何报告：
   - 平面数量；
   - 匹配平面数量；
   - 平面残差前后；
   - 旋转和平移修正；
   - 拒绝原因。
5. 只对异常工位尝试小范围人工修正。
6. 每次修正后重新检查：
   - `alignment_audit.png`
   - `section_alignment_audit.png`
   - `vertical_section_raw.png`
   - `run_summary.json`
7. 如果仍为 `persistent_gap`，优先重新采集缺口区域，不能继续靠参数掩盖。

### 阶段 1：采集和校准

- 增加采集清单和工位映射；
- 外部化固定工位姿态矩阵；
- 增加标定块 ROI 预览和点数/平面数检查；
- 保存相机序列号、曝光、工作距离等元数据；
- 建立标准件重复采集数据集。

### 阶段 2：配准稳健性

- 平面、边缘、角点联合匹配；
- 多候选初始位姿和不确定性评分；
- 标定块局部遮挡下的鲁棒匹配；
- 对称结构的镜像/翻转歧义检测；
- 位姿图加入边权、置信度和异常边隔离；
- 对每个工位输出可解释的失败原因。

### 阶段 3：覆盖和融合

- 为每个融合点保存来源工位和支持视角数；
- 生成三维覆盖热图，而不只显示截面；
- 在重叠区提供距离分布和局部厚度诊断；
- 对重叠点做真实代表点选择，不改变独有点；
- 支持按区域重新融合，不必整组重复计算。

### 阶段 4：截面和测量

- 目标区域引导截面平面选择；
- 通过局部法向和边缘稳定性推荐平面；
- 将“建议平面”和“正式平面”严格区分；
- 输出截面覆盖率、来源覆盖、缺口位置和置信等级；
- CAD 测量结果增加不确定度和重复性指标。

### 阶段 5：性能和现场部署

- PLY 读取、去噪、变换和融合的缓存；
- CPU/GPU 后端结果一致性测试；
- 大点云分块处理和内存上限；
- 运行中断后的可恢复任务；
- 自动保存每个阶段的中间结果；
- 现场一键生成压缩诊断包。

### 阶段 6：验收和维护

- 建立标准件金样和允许误差；
- 每个零件族至少进行多次重复采集；
- 统计拼接平移/旋转重复性；
- 统计截面点数和缺口重复性；
- 统计 CAD 偏差的重复性、最大误差和 P95；
- 建立算法版本和 profile 版本的回归基线。

## 12. 建议验收指标

最终阈值应由设备精度和零件公差确定，软件先提供以下结构化指标：

- 每个工位标定块点数、fitness、RMSE；
- 每个工位几何修正旋转和平移；
- 位姿图接受边和拒绝边；
- 每个视角目标覆盖体素数；
- 单视角独有覆盖比例；
- 重叠区距离中位数和 P90；
- 截面原始点数、清理后点数；
- 截面连续分量数、横向跨度和缺口比例；
- CAD 路径有效点数、偏差 P90 和角度偏差；
- 正式测量是否允许。

建议把“算法质量”和“数据覆盖”分开报告：

```text
registration_quality  配准是否可靠
coverage_quality      是否把目标区域拍全
section_quality       选定截面是否完整
measurement_quality   是否允许正式出值
```

## 13. 代码清理顺序

为避免一次重写造成现场不可用，建议按以下顺序实施：

1. 保持现有输出格式和测试，先抽取 `quality.py`。
2. 把工位清单和校准文件接入 `io.py` / `calibration.py`。
3. 把 `process_group` 改成只编排各阶段。
4. 把融合和截面函数迁入独立模块。
5. 将旧的截面共识姿态候选函数标记为诊断或迁移用途。
6. 将旧版 `process_media_five_clouds.py`、旧网页入口和实验代码移入 `legacy/`。
7. 连续两个版本通过标准件回归后，再删除旧正式入口。

删除代码的原则不是“文件越少越好”，而是：

- 生产路径只有一条；
- 诊断路径必须显式；
- 旧路径不能被页面按钮隐式触发；
- 每个输出都能追溯到输入、参数和算法版本。

## 14. 最终设计结论

软件的核心不是“把几组点云尽量叠在一起”，而是建立一个可证明的测量链：

```text
采集完整性
  -> 标定块统一坐标
  -> 受限刚体配准
  -> 保留互补覆盖的融合
  -> 融合云基线截面和多截面诊断
  -> 冻结截面
  -> CAD 偏差和角度测量
  -> 质量闸门与可追溯报告
```

专利中的公共视场、多平面几何和邻域一致性可以帮助提高稳健性，但不能替代当前设备的真实采集覆盖。只要原始点云没有拍到某个区域，算法就只能报告缺口，不能合法地制造该区域的测量数据。
